# PowerChapter prototype

Static, no build step. Open `index.html` through any web server, or upload the folder as-is to GitHub Pages / Netlify.

- Edit chapters, counties, benefits and sample content in `assets/data/chapters.js`.
- Add photos to `assets/photos/` using the file names shown in each placeholder
  (`{chapter-id}-hero.jpg`, `{chapter-id}-logo.png`, `{chapter-id}-leader-1.jpg`, `benefit-{id}.jpg`).
- `BUILD-SPEC.md` is the production specification.
- `robots.txt` and the `noindex` meta tag keep this prototype out of search engines.
